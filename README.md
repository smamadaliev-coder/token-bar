# token-bar

Мод для Claude Code, который показывает расход токенов прямо во время работы.

- **Над полем ввода** — полоска заполнения контекста: `Контекст ████░░░░ 15% (154k / 1000k) · 5ч 42% · ~$2.50`.
- **Справа от поля ввода** — короткий индикатор: `ctx 15% · 5ч 42%`.

Цвет меняется сам: зелёный, после 50% жёлтый, после 80% красный.
«5ч» и «неделя» — сколько израсходовано из лимитов подписки (видно, только если они есть).
Сумма в долларах — примерная оценка, а не настоящий счёт.

Работает во вкладке Code приложения Claude и в Claude Code в терминале. В обычном чате моды не работают.

## Установка

В терминальной сессии Claude Code:

```
/plugin install token-bar --marketplace smamadaliev-coder/token-bar
```

Или из обычного терминала:

```
claude plugin install token-bar --marketplace smamadaliev-coder/token-bar
```

На вопрос `Add marketplace?` ответьте `y`, затем нажмите Enter, чтобы выбрать область установки.

В приложении Claude (где `/plugin` не работает): нажмите + рядом с полем ввода, затем Plugins → Add marketplace → `smamadaliev-coder/token-bar` → Add plugin.
